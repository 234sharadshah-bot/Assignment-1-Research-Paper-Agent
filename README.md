# Assignment 1 – AI-Powered Research Paper Agent

## Project Overview

This project focuses on developing an AI-powered Research Paper Agent using Google AI Studio and AI-assisted application development (Vibe Coding).

The application is designed to assist users with research paper-related tasks by using artificial intelligence and natural language prompts. The project demonstrates how AI can be used to develop applications through few-shot prompting and Chain-of-Thought prompting techniques.

## Project Objective

The primary objective of this assignment is to develop an AI-powered application using Google AI Studio and store the generated project files in a public GitHub repository.

## Tools and Technologies

- **Google AI Studio:** AI-assisted application development.
- **Artificial Intelligence:** Powers the research paper agent.
- **Prompt Engineering:** Few-Shot Prompting and Chain-of-Thought Prompting.
- **GitHub:** Version control and project file storage.
- **JSON:** Storage of structured project data.
- **Text Files:** Storage of project-related content.

## Key Project Components

### 1. AI-Powered Research Paper Agent
An AI-based application designed around research paper-related tasks using natural language instructions.

### 2. Prompt Engineering
The project uses prompting techniques to guide the AI in generating relevant and structured responses.

- Few-Shot Prompting
- Chain-of-Thought Prompting

### 3. Vibe Coding
The application is developed using natural language prompts through Google AI Studio's Build feature.

### 4. GitHub Repository
The generated JSON and text files are stored in a public GitHub repository for project submission.

## Development Process

1. Open Google AI Studio.
2. Sign in using a personal Google account.
3. Create a free Google Cloud project and obtain an API key if required.
4. Navigate to the Build tab.
5. Develop the Research Paper Agent using natural language prompts.
6. Apply Few-Shot or Chain-of-Thought prompting techniques.
7. Generate and save the project files.
8. Upload the JSON and text files to GitHub.
